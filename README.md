# Azeroth Survivors 한국어 패치

[다운로드](https://github.com/uckdoman/azeroth-survivors-korean/releases/latest/download/AzerothSurvivors_KoreanPatch.exe)

## 설치

1. 게임을 종료하세요.
2. 내려받은 패치 파일을 `AzerothSurvivors.exe`가 있는 폴더에 넣고 실행하세요.
3. `AzerothSurvivors_KoreanLauncher.exe`로 게임을 실행하세요.

게임 버전은 유지하며, 적용할 수 있는 기존 번역만 사용합니다. 새로 추가되거나 바뀐 문구는 영어로 표시됩니다.
한글 실행기는 GitHub의 새 한글 패치를 자동으로 확인합니다.
설치·업데이트 중에는 진행창에서 현재 작업을 확인할 수 있습니다.

[롤백 다운로드](https://github.com/uckdoman/azeroth-survivors-korean/releases/latest/download/AzerothSurvivors_Rollback.exe): 게임 폴더에서 실행하면 패치 적용 전의 같은 게임 버전으로 복원합니다. 세이브는 유지됩니다.
