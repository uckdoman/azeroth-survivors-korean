# Azeroth Survivors 한국어 패치

아제로스 서바이버 Windows 0.2.0용 한글 패치입니다.

**[한글 패치 다운로드](https://github.com/uckdoman/azeroth-survivors-korean/releases/latest/download/AzerothSurvivors_KoreanPatch.exe)** · [업데이트 내역](https://github.com/uckdoman/azeroth-survivors-korean/releases)

## 설치

1. 게임을 종료하세요.
2. 내려받은 `AzerothSurvivors_KoreanPatch.exe`를 게임 폴더에 넣으세요. `AzerothSurvivors.exe`와 `Data` 폴더가 있는 위치입니다.
3. 패치 설치기를 실행하세요. 폴더를 따로 선택할 필요 없이 그 위치에 적용합니다.
4. 이후에는 `AzerothSurvivors_KoreanLauncher.exe`로 게임을 시작하세요. 새 한글 패치가 있으면 자동으로 받아 적용합니다.

기존 설치기로 한글 패치를 적용하셨다면 새 설치기를 실행해 업데이트 실행기를 추가할 수 있습니다. 영문판으로 복원할지 묻는 창에서는 **‘아니오’**를 선택하세요.

## 번역

주문·아이템·NPC·지역·직업·종족 이름은 Wowhead 한국어 표기를 기준으로 맞췄습니다. 예를 들어 Whirlwind는 **소용돌이**입니다.
게임 메뉴와 고유 효과 설명, 대사는 설치본의 영문 내용을 번역했습니다.

## 업데이트와 원본 복원

한국어 실행기는 게임을 시작하기 전에 새 한글 패치를 확인합니다. 인터넷이 연결되지 않으면 현재 설치된 버전으로 실행합니다.
기존 `AzerothSurvivors.exe`로 직접 시작할 수도 있지만, 이 경우 업데이트 확인은 건너뜁니다.

영문판으로 돌아가려면 게임을 종료하고 패치 설치기를 다시 실행한 뒤 복원을 선택하세요. 복원 후에는 한글 패치를 다시 자동 적용하지 않습니다.

## 알아둘 점

- 제작 시 확인한 Windows 0.2.0 파일을 지원합니다. 같은 버전이라도 파일이 다르면 설치기가 적용을 중단합니다. [지원 파일 정보](DEVELOPMENT.md#지원-파일)에서 확인할 수 있습니다.
- Windows .NET Framework 4.5 이상이 필요합니다.
- 일부 문구는 영어로 남아 있습니다. 대사는 와우 한국어 클라이언트의 문구와 다를 수 있습니다.
- 게임 자체가 업데이트되면 그 버전에 맞는 새 한글 패치가 필요합니다.
- 모든 게임 화면의 번역과 표시를 확인한 상태는 아닙니다. 문제가 있으면 [이슈](https://github.com/uckdoman/azeroth-survivors-korean/issues)에 화면과 게임 버전을 알려주세요.

빌드·배포 방법과 검사 기록은 [개발 문서](DEVELOPMENT.md)에 있습니다.
