# Azeroth Survivors 한국어 패치

Windows 0.2.0 설치본을 대상으로 만든 한국어 패치와 업데이트 실행기입니다.
게임 원본이나 세이브를 제공하지 않습니다. 모든 0.2.0 빌드가 같은 파일은 아니며, 지원하는 실행 파일과 기본 자산의 해시가 일치할 때만 적용합니다.

## 설치

1. 게임을 종료합니다.
2. Releases에서 `AzerothSurvivors_KoreanPatch.exe`를 내려받아 원래 `AzerothSurvivors.exe`와 `Data` 폴더가 있는 위치에 넣습니다.
3. 패치 설치기를 실행합니다. 폴더 선택 없이 같은 위치에 적용하고 원본을 `한글패치_원본백업`에 보관합니다.
4. 이후에는 `AzerothSurvivors_KoreanLauncher.exe`로 실행합니다. 새 한글 패치가 있으면 확인·다운로드·설치한 뒤 게임을 시작합니다.

인터넷이 연결되지 않으면 설치된 게임을 실행합니다. 기존 `AzerothSurvivors.exe`를 직접 실행하면 업데이트 확인을 건너뜁니다.
원본 복원은 설치기를 다시 실행한 뒤 복원을 선택합니다. 복원 상태에서는 실행기가 한글 패치를 다시 자동 적용하지 않습니다.
세이브 데이터는 읽거나 수정하지 않습니다.

## 번역 기준

와우의 주문·아이템·NPC·지역·직업·종족 명칭은 Wowhead의 영문/한국어 동일 ID를 대조했습니다. Whirlwind는 `소용돌이`처럼 기존 와우 한국어 이름을 따릅니다.
게임 고유 효과 설명과 대사는 설치본 영문을 별도로 번역했습니다. 대사가 공식 한국어 클라이언트와 동일한지는 검증하지 않았습니다.
1,281개 문구, 주문 데이터 3,406개 표시 이름, 지역 데이터 12개 표시 이름을 패치했습니다. 일부 문구와 확인되지 않은 고유명칭은 영어로 남을 수 있습니다.

## 지원 파일

- 게임 실행 파일 SHA-256: `64fa48a5cdc3afc1621a1d7ac7426f287e2b99021a8a2b50aacc360606bb903a`
- 기본 `Data/patch.MPQ` SHA-256: `49473c3cd0f47cd949e579240ea694c793aab813549920f1073ef73017364adf`
- Windows .NET Framework 4.5 이상

게임 자체 업데이트는 자동 번역하지 않습니다. 게임 파일이 바뀌면 새 파일을 확인해 호환되는 한글 패치를 제작해야 합니다.
자동 업데이트는 설치기로 원본을 백업한 설치본을 대상으로 합니다. 실행 파일만 복사한 한글판에는 원본 백업이 필요합니다.

## 업데이트 배포

`update.json`은 RSA-2048/SHA-256 서명이 있는 업데이트 안내 파일입니다. 실행기는 내장 공개키로 이를 검증하고, 지정 저장소의 설치기 URL·파일 크기·SHA-256을 확인한 뒤 설치기를 실행합니다.
버전은 `0.2.0.2`처럼 게임 버전 세 자리와 한글 패치 개정 번호로 구성합니다. 릴리스 태그는 `v0.2.0-ko.2`입니다.

1. 새 번역 파일에 맞는 설치기를 빌드합니다. Installer의 현재 해시와 개정 번호를 갱신하고, `PreviousGameHashes`/`PreviousOverlayHashes`에 지원할 기존 공개 버전의 정확한 해시를 추가합니다.
2. 실제 설치기와 일치하는 배포정보 JSON, 릴리스 설명을 준비합니다.
3. 공개 저장소 밖에 보관한 서명 키를 사용해 `tools/Publish-Release.ps1`을 실행합니다. 먼저 초안 릴리스에 설치기와 서명된 안내 파일을 모두 올리고, 완료 후 최신 릴리스로 공개합니다. `-DraftOnly`로 공개 전 검토할 수 있습니다.

서명 키를 잃으면 기존 실행기에서 새 서명을 신뢰할 수 없으므로 별도로 백업해야 합니다. 비공개 키, 게임 원본, 세이브, 테스트용 게임 복사본은 저장소에 포함하지 않습니다.
실행기는 안정된 다운로드·검증 기능만 담당하며 기존 실행기 파일을 업데이트 설치 중에 덮어쓰지 않습니다. 실행기 자체 또는 공개키가 바뀌는 경우에는 새 실행기를 별도로 배포해야 합니다.

## 검증

게임은 실행하지 않았습니다. 실행기는 서명 변조·외부 URL·파일 크기·버전 비교·오프라인·복원 상태 등을 31개 독립 테스트로 확인했습니다.
설치·중복 설치·복원·이전 파일 교체·실패 복구는 게임을 실행하지 않는 분리된 파일 복사본에서 14개 검사에 통과했습니다.
GitHub 공개 릴리스를 로그인 없이 내려받았고, 실제 실행기의 `/check-only`에서 현재 버전 확인(0)과 새 설치기 다운로드·검증(10)을 확인했습니다. 이 검사 모드는 설치기나 게임을 시작하지 않습니다.
모든 게임 화면과 플레이 상황의 번역을 실행 검증한 상태는 아닙니다.

폰트 Noto Sans KR의 OFL 라이선스는 설치기와 설치 후 백업 폴더에 포함됩니다.
